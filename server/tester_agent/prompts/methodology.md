# 测试用例设计方法论

设计用例时按以下方法识别测试点，保证覆盖有效等价范围与关键风险：

1. **等价类划分**：将输入域划分为有效/无效等价类，每个等价类取一个代表值；不得只验证正常值。
2. **边界值分析**：在等价类边界及两侧取值（最小值、略小于最小值、略大于最小值、最大值、略大于最大值）；缺陷集中在边界。
3. **判定表**：多条件组合决定输出时，列出条件桩与动作桩，覆盖每条规则；注意条件间的约束与互斥。
4. **场景法**：以基本流（正常路径）和备选流（异常/分支路径）构造场景，每条场景对应一个端到端用例。

用例须包含：清晰标题、优先级（P0/P1/P2）、前置条件、带序号的操作步骤、每步预期结果；只依据已确认的需求与知识库信息，不臆造业务规则。
